# AI Real Estate Sales Platform

Premium single-site real-estate sales platform starter.

## Run
1. Copy `backend/.env.example` to `backend/.env`.
2. Add your `GROQ_API_KEY`.
3. `pip install -r backend/requirements.txt`
4. `python backend/app.py`
5. Open `http://localhost:8000`

Demo owner credentials shown in UI are for demo only. Replace authentication with a real production auth system before selling.

This package is a runnable MVP/demo foundation, not a claim of security certification or production penetration testing. For production use PostgreSQL, HTTPS, object storage, backups, monitoring and real auth/session controls.
